# Registros do catálogo

| Arquivo | Função |
| --- | --- |
| [arquivos.json](arquivos.json) | Identidade, origem, caminho, hashes e cobertura dos materiais |
| [caminhos.csv](caminhos.csv) | Mapa dos 117 caminhos anteriores e destinos atuais |
| [matriz-integridade.json](matriz-integridade.json) | Verificação dos valores das seis abas da matriz após a migração |

O [catálogo legível](../catalogo.md) é a entrada recomendada. Os IDs S identificam fontes, D identificam derivados e P identifica a nota de origem vazia. Os IDs M da matriz têm outra função e foram preservados.
