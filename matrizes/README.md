# Matriz de mensagens por etapa

**[Abrir ou baixar a planilha](mensagens-por-etapa.xlsx)** · [Relatório de cobertura](cobertura.md)

A planilha cobre 45 documentos e contém 2.171 registros de origem. Os 60 arquivos complementares estão no catálogo, aguardando extração para a matriz.

| Aba | Uso |
| --- | --- |
| Matriz integral | Uma linha por documento, mensagens agrupadas por etapa |
| Mensagens integrais | Registro por bloco, IDs M, texto completo, tipo e localização |
| Fontes e cobertura | Metadados das 45 fontes e hashes do snapshot de extração |
| Contexto integral | Texto de apoio para leitura no contexto original |
| Adaptações iniciais | Histórico das 96 mensagens adaptadas da primeira entrega |
| Modelos V5 | Quatro rotas com a seleção de 43 mensagens |

Os caminhos das células foram atualizados para esta organização. Textos, IDs, condições, hashes históricos e referências de linha permanecem no snapshot de extração. Os hashes atuais de arquivo estão no [inventário](../docs/inventario.md).

As seis abas têm seus valores conferidos pelo [registro de integridade](../catalogo/matriz-integridade.json); estilos, fórmulas e tabelas foram preservados na reorganização.
